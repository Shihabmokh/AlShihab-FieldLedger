# الدفتر الميداني – الشهاب

تطبيق أندرويد يعمل بدون إنترنت لإدارة الدفتر المالي الميداني لمشاريع **مكتب الشهاب للمقاولات العامة**، مطابق للنماذج الورقية (3F، 4F، A2-F، B2-F، 31F، 5F، 7F، 8F، 20F، 24T، 25T).

## المرحلة الأولى (الحالية)
- مشاريع متعددة ببياناتها الأساسية (المحافظة، المديرية، العزلة، القرية، موقع العمل، المسؤولون)
- سجل عمال عام (مثل جهات الاتصال) - إضافة وتعديل وإيقاف، بدون حذف
- اتفاق العامل في كل مشروع: يومية / مقاولة، أساسي / مؤقت، أجر يومي، سعر ساعة إضافية، عملة
- كشف الحضور والمسحوبات اليومية (3F) مع حساب المستحق تلقائياً
- كشف حركة الصندوق (A2-F) والمصروفات الأخرى (B2-F) بأرصدة مستقلة لكل عملة
- كشف حساب لكل عامل وتقرير مالي تراكمي للمشروع
- قفل الكشف بعد 24 ساعة من إنشائه

## الحماية
- قفل التطبيق برمز سري (PBKDF2) مع البصمة اختيارياً وإيقاف مؤقت بعد المحاولات الخاطئة
- قاعدة بيانات مشفّرة بالكامل (SQLCipher AES-256) ومفتاحها مغلّف في Android Keystore
- منع الحذف على مستوى قاعدة البيانات (Triggers) وسجل تدقيق غير قابل للتعديل
- كشف إرجاع ساعة الجهاز لمنع تجاوز قفل الـ24 ساعة
- منع النسخ الاحتياطي السحابي ونقل البيانات بين الأجهزة
- تشويش الكود (R8)، فحص توقيع التطبيق، وتنبيه الأجهزة مكسورة الحماية

## البناء
يُبنى تلقائياً عبر GitHub Actions عند كل رفع إلى `main`، ويُنشر ملف APK في صفحة Releases.
مفاتيح التوقيع تُحفظ في Secrets المستودع: `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`.

الحد الأدنى: Android 6.0 (API 23).
